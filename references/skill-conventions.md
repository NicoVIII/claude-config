# Skill conventions

Read this before writing or editing a skill in `~/.claude/skills`. Conventions for the repo itself — check suite, tests, doc placement — are in [`repo.md`](repo.md). Neither file auto-loads, so read them rather than a remembered copy.

- Write and refine skills with the most capable model available (currently Fable, otherwise Opus), even when the skill's suggested execution model is Sonnet: skill text is written once but steers every future run, and the hard part is anticipating how a smaller executor will misread it. Mechanical edits (typos, renames) don't need this. Deliberate exception: `skill-retro`'s suggested *run* model stays Opus — its edits are anchored to observed friction rather than open-ended authoring, and it runs after every skill iteration, so cost weighs heavier there (1468685).
- Before writing an executable helper for a skill — or deciding whether it should be a shell script or an F# project, and whether it belongs in `bin/` or beside one SKILL.md — read [`helpers.md`](helpers.md). That is the one place those rules live.
- `skills/*/SKILL.md` frontmatter must start at byte 0 (nothing above the first `---`, or it silently fails to parse). The `description` field is the model's only trigger signal — keep it rich in trigger phrases.
- Skills below 🟢 Usable in the README maturity table (🚧 WIP, 🧪 Experimental) end with a one-line feedback footer asking the executing agent to surface friction, copied verbatim from [`skill-footer.md`](skill-footer.md) — the canonical wording, so no skill is another's source. Add it to every new skill; remove it when a skill graduates to Usable — mature skills are daily drivers where the footer is noise, and `/skill-retro` on demand covers them. `/skill-retro` turns the surfaced friction into skill edits. Nothing follows the footer — upstream attributions belong in the README's credits line, since a `SKILL.md` loads into context on every invocation.
- The agent-marker attribution norm lives in `author-skill`, deliberately not in `CLAUDE.md`: it only bites when a skill writes where others read, so global memory would tax every session everywhere (a3cd73c).
